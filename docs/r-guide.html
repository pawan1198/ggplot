Module 01 — Foundation

Getting Started with R

R is one of the most popular programming languages in statistical computing. Open-source, easy to learn, and powerful for manipulating and visualizing data.

Download & Install R and RStudio

To use R, you need two things: R itself (the language engine) and RStudio (the IDE that makes it comfortable to use). Download links:

  • RStudio: https://www.rstudio.com/products/rstudio/download/
  • R (CRAN): https://cran.r-project.org/

Debian / Ubuntu / Linux Mint

bash Terminal 
# Install R base (as superuser)
sudo apt-get install r-base

# Install RStudio — download .deb from rstudio.com first, then:
sudo apt install -f ./rstudio-2024.x.x-amd64.deb

# Alternative: use the desktop package manager
sudo apt-get install rstudio-desktop

Windows — Step by Step

  1. Go to cran.r-project.org → "Download R for Windows" → save the .exe
  2. Run the .exe file and follow the installation wizard
  3. Go to rstudio.com/products/rstudio/download
  4. Download the RStudio Desktop installer (.exe) and run it
📌
Note: Always install R before RStudio so RStudio can detect your R installation automatically.

macOS — Step by Step

  1. Go to cran.r-project.org → "Download R for macOS" → download the .pkg
  2. Double-click and follow the installer prompts
  3. Download RStudio .dmg → drag to Applications folder
bash Homebrew (alternative) 
brew install --cask r
brew install --cask rstudio

⚠️ Download the version matching your Mac OS version (Intel vs Apple Silicon).

The Working Directory

The working directory is the file path R uses as the starting point for all relative file paths — the default location for importing and exporting files.

R Working Directory 
# Returns your current working directory
getwd()
# e.g. output: "/Users/pawan/Documents/R"

# Change your working directory to a desired path
setwd("~/R")
setwd("/home/pawan/projects")  # Linux/Mac
setwd("C:/Users/Pawan/R")       # Windows (use / not \)

Using Packages in R

R packages are collections of functions and tools developed by the R community. They extend R's capabilities — from data manipulation to machine learning to visualization.

R Package Management 
# Install a package (only needed once)
install.packages("ggplot2")
install.packages("tidyverse")  # Installs ggplot2, dplyr, tidyr, etc.

# Install multiple packages at once
install.packages(c("ggplot2", "ggthemes", "patchwork"))

# Load a package (every session)
library(ggplot2)
library(tidyverse)

# Check installed packages
installed.packages()[, "Package"]

# Update all packages
update.packages()
💡
Tip: You only need to install.packages() once. But you need library() at the start of every new R session.

Vectors in R

A vector is a one-dimensional array that holds numeric, character, or logical data. It is the fundamental data structure in R.

Types of Vector

🔢

Numeric

e.g. c(1, 2, 3.5)
Whole numbers and decimals

🔤

Character

e.g. c("a", "b", "hello")
Text strings in quotes

🏷️

Factor

Categorical data stored as levels — useful for grouping

✅

Boolean

e.g. c(TRUE, FALSE)
Logical true/false values

Creating Vectors

R Vector creation 
# Numeric vector with comma
c(1, 3, 5)

# Integer sequence with colon (faster for sequences)
c(1:7)   # = c(1, 2, 3, 4, 5, 6, 7)

# Character vector
c("a", "b", "hello")

# Store with -> (R convention) or =
c(1:10) -> v
v
c("my", "vector") -> words

# Sequence with step size
seq(1, 20, by = 3)   # 1 4 7 10 13 16 19

# Repeated values
rep(3, times = 4)          # 3 3 3 3
rep(c(1:4), times = 2)    # 1 2 3 4 1 2 3 4
rep(c(1:4), each = 2)     # 1 1 2 2 3 3 4 4

# Check the type of a vector
class(v)   # "integer"

Data Frames

A data frame is the core data structure for tabular data in R — like a spreadsheet or database table. Each column is a vector; all columns have the same length.

📌
Syntax: df[row, column] — the first argument is always the row, the second is the column. Example: df[1:9, c(2,5,6)] selects rows 1–9 and columns 2, 5, 6.
R Creating & accessing data frames 
# Create a data frame
data.frame(x = 1:7,
           y = c("Sun","Mon","Tue","Wed","Thu","Fri","Sat")) -> df
df

# Accessing rows and columns
df[, 2]    # All rows of column 2
df[2, ]    # All columns of row 2
df$x       # Column 'x' by name (returns a vector)
df[1:3, 1] # Rows 1–3, column 1

# Useful info functions
nrow(df)   # Number of rows
ncol(df)   # Number of columns
dim(df)    # Both dimensions
str(df)    # Structure overview
head(df)   # First 6 rows
tail(df)   # Last 6 rows
summary(df)# Statistical summary

Combining Data Frames

R cbind & rbind 
df1 <- data.frame(x = 1:3, y = c("a","b","c"), z = 12:14)
df2 <- data.frame(x = 4:6, y = c("A","B","C"), z = 21:23)

cbind(df1, df2)  # Combine by columns (side by side) — must have same nrow
rbind(df1, df2)  # Combine by rows (stack) — must have same column names

Subsetting Data Frames

R Subsetting 
# Built-in datasets (great for practice)
data(mtcars)    # Car performance data
data(iris)      # Fisher's iris flowers
data(economics) # US economic data (in ggplot2)

# subset() — filter rows based on condition
subset(mtcars, mpg > 25) -> fast_cars  # Cars with >25 mpg

# Select specific columns
subset(mtcars, select = c("mpg", "cyl", "hp")) -> small_df

# Using brackets
mtcars[mtcars$mpg > 25, ]    # Same as subset above
mtcars[, c("mpg", "hp")]     # Select columns

# dplyr (tidyverse) — more readable
library(dplyr)
mtcars |> filter(mpg > 25)
mtcars |> select(mpg, cyl, hp)
mtcars |> arrange(desc(mpg))

Saving Plots with ggsave()

After creating a ggplot2 plot, use ggsave() to export it to a file. It automatically uses the last plot unless you specify otherwise.

R ggsave 
# Save the last plot
ggsave("my_plot.png", width = 8, height = 5, dpi = 300)

# Save a specific plot object
p <- ggplot(mtcars, aes(x = wt, y = mpg)) + geom_point()
ggsave("plot.pdf", plot = p, width = 10, height = 7)

# Formats: png, pdf, svg, tiff, jpg, eps
ggsave("plot.svg", device = "svg")
