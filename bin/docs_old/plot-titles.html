Module 03 — Labels

Titles, Labels & Annotations

Every ggplot2 plot can have a title, subtitle, caption, and tag. There are two main ways to add them — via ggtitle() or labs().

Title & Subtitle

ggtitle() is a convenience function dedicated to adding a title and subtitle.

R ggtitle() 
library(ggplot2)
data <- iris

ggplot(data, aes(x = Sepal.Width, y = Petal.Width, fill = Species)) +
  geom_bar(stat = "identity") +
  facet_wrap(~Species) +
  ggtitle("Title of the plot",
          subtitle = "Subtitle of the plot")

labs() is more versatile — it sets titles, axis labels, legend labels, and more all in one call.

R labs() — all labels in one call 
library(ggplot2)
data <- iris

ggplot(data, aes(x = Sepal.Width, y = Petal.Width, fill = Species)) +
  geom_bar(stat = "identity") +
  facet_wrap(~Species) +
  labs(
    title    = "Title of the plot",
    subtitle = "Subtitle of the plot",
    x        = "Sepal Width",
    y        = "Petal Width",
    fill     = "Iris Species"
  )

Title Position

By default, the title is aligned to the panel (the plot area). Set plot.title.position = "plot" to align to the full plot including axis labels.

R Title position control 
# Default: aligned to the panel (data area)
ggplot(data, aes(x = Sepal.Width, y = Petal.Width)) +
  geom_area(fill = rgb(0, 0.5, 1, alpha = 0.5)) +
  labs(title = "Aligned to panel (default)")

# Aligned to the full plot (left edge of margin)
ggplot(data, aes(x = Sepal.Width, y = Petal.Width)) +
  geom_area(fill = rgb(0, 0.5, 1, alpha = 0.5)) +
  labs(title = "Aligned to full plot") +
  theme(plot.title.position = "plot")   # "panel" | "plot"

Subtitle

A subtitle appears below the title in a slightly smaller font. Add it the same way as the title.

R Subtitle examples 
# Option 1: ggtitle with subtitle argument
ggplot(data, aes(x = Sepal.Width, y = Petal.Width)) +
  geom_area(fill = rgb(0, 0.5, 1, alpha = 0.5)) +
  ggtitle("Main Title", subtitle = "Subtitle below")

# Option 2: labs() with subtitle argument
ggplot(economics, aes(date, unemploy)) +
  geom_area(fill = rgb(0, 0.5, 1, alpha = 0.5)) +
  labs(
    title    = "US Unemployment Over Time",
    subtitle = "Monthly data from 1967 to 2015"
  )

Caption

A caption appears at the bottom-right of the plot. Great for adding data source citations.

R Adding a caption 
ggplot(economics, aes(date, unemploy)) +
  geom_area(fill = rgb(0, 0.5, 1, alpha = 0.5)) +
  labs(
    title   = "US Unemployment",
    caption = "Source: Bureau of Labor Statistics"
  )

# Position caption to left instead of right (default)
ggplot(economics, aes(date, unemploy)) +
  geom_area(fill = rgb(0, 0.5, 1, alpha = 0.5)) +
  labs(caption = "Source: ggplot2 economics dataset") +
  theme(plot.caption.position = "plot",
        plot.caption = element_text(hjust = 0))  # 0=left, 1=right

Tag

A tag is placed at the top-left of the plot. Useful for labeling panels (A, B, C) in a multi-panel figure.

R Adding a tag 
ggplot(economics, aes(date, unemploy)) +
  geom_area(fill = rgb(0, 0.5, 1, alpha = 0.5)) +
  labs(tag = "A")  # Top-left corner label

Styling Labels with theme()

Use theme() to control the font, size, color, and alignment of every label element.

R Full label styling 
ggplot(mtcars, aes(x = wt, y = mpg)) +
  geom_point(color = "steelblue", size = 3) +
  labs(
    title    = "Vehicle Weight vs Fuel Economy",
    subtitle = "Each dot is one car model from 1974",
    caption  = "Source: Motor Trend US magazine",
    x        = "Weight (1,000 lbs)",
    y        = "Miles per Gallon"
  ) +
  theme_minimal() +
  theme(
    plot.title    = element_text(face = "bold", size = 18, color = "#1a1b20"),
    plot.subtitle = element_text(size = 13, color = "#6b6760", margin = margin(b=12)),
    plot.caption  = element_text(size = 10, color = "#aaa", hjust = 1),
    axis.title    = element_text(size = 12, face = "italic"),
    axis.text     = element_text(size = 11)
  )

Removing & Rotating Axis Text

R Axis text manipulation 
ggplot(mtcars, aes(x = row.names(mtcars), y = mpg)) +
  geom_bar(stat = "identity", fill = "steelblue") +
  theme(
    # Rotate x-axis labels 45 degrees
    axis.text.x  = element_text(angle = 45, hjust = 1),

    # Remove y-axis label text
    axis.text.y  = element_blank(),
    axis.ticks.y = element_blank(),

    # Remove axis titles
    axis.title.x = element_blank()
  )
