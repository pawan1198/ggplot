Quick Reference

All key functions at a glance — everything from ggplot2 setup to geoms, themes, scales, and combining plots. Plus a practice quiz at the bottom.

Setup & Template

R The complete ggplot2 template 
install.packages("ggplot2")
library(ggplot2)

# Full template
ggplot(data        = <DATA>,
       mapping    = aes(<MAPPINGS>)) +
  <GEOM_FUNCTION>(
    mapping    = aes(<MAPPINGS>),
    stat       = <STAT>,
    position   = <POSITION>
  ) +
  <COORDINATE_FUNCTION> +
  <FACET_FUNCTION> +
  <SCALE_FUNCTION> +
  <THEME_FUNCTION>

Combining Plots

grid.arrange(p1, p2, ncol=2)gridExtra: 2 columns
plot_grid(p1, p2, labels="AUTO")cowplot: auto panel labels
