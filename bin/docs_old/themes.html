Module 04 — Appearance

Themes & Styling

Control the entire non-data appearance of your plots. ggplot2 ships with 8 built-in themes, and extension packages provide dozens more — plus you can customize anything with theme().

Built-in Themes

ggplot2 comes with 8 themes out of the box. The default is theme_grey(). Click any theme card to see its code.

R theme code 

    

  


  
  

    
ggthemes Package

    
The ggthemes package contains highly popular themes, many mimicking styles from well-known publications. Some come with matching color scales.


    

      

        R Install & use ggthemes
        
      

      
install.packages("ggthemes")
library(ggplot2)
library(ggthemes)

cyls <- as.factor(mtcars$cyl)

ggplot(mtcars, aes(x = mpg, fill = cyls)) +
  geom_density(alpha = 0.7) +
  theme_economist() +                 # The Economist style
  scale_fill_economist() +             # Matching color palette
  theme(legend.position = "top")

hrbrthemes Package

    
hrbrthemes provides "typography-centric themes" — minimal, clean, with beautiful font choices. Created by Bob Rudis.

ggthemr Package

    
ggthemr works differently from other packages — you set a global theme that applies to ALL subsequent plots using the ggthemr() function, rather than adding a layer.


    

      ⚠️
      
Remember: Call ggthemr_reset() to return to the default ggplot2 theme after using ggthemr.

    


    

      

        R ggthemr usage
        
      

      
# Install from GitHub
##devtools::install_github('Mikata-Project/ggthemr')
library(ggthemr)
library(ggplot2)

cyls <- as.factor(mtcars$cyl)

# Set a global theme (affects ALL subsequent plots)
ggthemr("flat")

ggplot(mtcars, aes(x = mpg, fill = cyls)) +
  geom_density(alpha = 0.7) +
  theme(legend.position = "top")

# Reset to default when done
ggthemr_reset()

ggtech Package

    
ggtech provides themes inspired by major tech companies: Airbnb, Google, Twitter, Facebook, and more.


    

      

        R ggtech usage
        
      

      
# Install from GitHub
##devtools::install_github("ricardo-bion/ggtech", dependencies=TRUE)
library(ggtech)
library(ggplot2)

cyls <- as.factor(mtcars$cyl)

ggplot(mtcars, aes(x = mpg, fill = cyls)) +
  geom_density(alpha = 0.7) +
  ggtitle("Title of the plot") +
  theme_tech(theme = "airbnb") +      # airbnb | google | twitter | facebook
  scale_fill_tech(theme = "airbnb") +  # Matching color scale
  theme(legend.position = "top")

    

  


  
  

    
ggdark Package

    
ggdark provides dark versions of all 8 built-in ggplot2 themes. It can also convert any theme to dark mode using dark_mode().


    

      

        R ggdark usage
        
      

      
install.packages("ggdark")
library(ggdark)
library(ggplot2)

cyls <- as.factor(mtcars$cyl)

# Dark version of theme_gray (the default)
ggplot(mtcars, aes(x = mpg, fill = cyls)) +
  geom_density(alpha = 0.7) +
  dark_theme_gray() +
  theme(legend.position = "top")

# All dark_theme_* equivalents:
# dark_theme_gray()     dark_theme_bw()       dark_theme_dark()
# dark_theme_classic()  dark_theme_minimal()  dark_theme_light()
# dark_theme_linedraw() dark_theme_void()

# Convert ANY theme to dark mode
ggplot(mtcars, aes(x = mpg, fill = cyls)) +
  geom_density(alpha = 0.7) +
  dark_mode(theme_economist())

    

  


  
  

    
Setting a Global Theme

    
Use theme_set() to apply a theme to all plots in your session. Save the old theme first so you can restore it.


    

      

        R theme_set()
        
      

      
library(ggplot2)

# Save current theme and set a new global theme
old <- theme_set(theme_dark())

# All plots now use theme_dark automatically
cyls <- as.factor(mtcars$cyl)
ggplot(mtcars, aes(x = mpg, fill = cyls)) +
  geom_density(alpha = 0.7) +
  theme(legend.position = "top")

# Reset to the previous theme
theme_set(old)

    

  


  
  

    
Custom Theme with theme()

    
The theme() function lets you override any visual element. Combine it with any base theme.


    

      

        R Full theme() customization
        
      

      
ggplot(mtcars, aes(x = mpg, y = wt, color = factor(cyl))) +
  geom_point(size = 3) +
  labs(title = "Custom Styled Plot") +
  theme_minimal() +
  theme(
    # Plot area background
    panel.background  = element_rect(fill = "#f0f4f8"),
    plot.background   = element_rect(fill = "white"),

    # Grid lines
    panel.grid.major  = element_line(color = "#dce3ec", size = 0.4),
    panel.grid.minor  = element_blank(),

    # Title & text
    plot.title        = element_text(face="bold", size=16, color="#1a1b20"),
    axis.title        = element_text(size=11, color="#6b6760"),
    axis.text         = element_text(size=10),

    # Legend
    legend.position   = "top",
    legend.title      = element_text(face="bold"),

    # Margins (T, R, B, L)
    plot.margin       = margin(20, 20, 20, 20)
  )
