Module 02 — Core Concepts

ggplot2 Introduction

ggplot2 is a powerful, open-source data visualization library for R. Based on the Grammar of Graphics, it provides a systematic approach to creating any statistical graphic.

What is ggplot2?

ggplot2 was developed by Hadley Wickham and is based on The Grammar of Graphics — a framework for describing any visualization as a combination of data, mappings, and geometric objects.

One of ggplot2's key strengths is its layered plot construction: you start with data, add aesthetics, then layer on geometric objects, scales, facets, and themes — each building on the last.

R Installation & basic template 
# Install once
install.packages("ggplot2")

# Basic syntax template
ggplot(data, aes(x, y)) + geom_*()

# Minimal working example
library(ggplot2)
ggplot(mtcars, aes(x = mpg, y = wt)) +
  geom_point()

The Grammar of Graphics — 7 Layers

Every ggplot2 visualization is composed of up to 7 layers. You build a plot by adding layers together with the + operator.

1
Data
The raw data frame that contains the variables you want to visualize. ggplot(data = mtcars, ...)
2
Aesthetics
Map variables to visual properties: x, y, color, fill, size, shape, alpha, linetype. aes(x = wt, y = mpg)
3
Geometries
The geometric shape used to represent data: points, lines, bars, boxes, areas. geom_point(), geom_line()
4
Facets
Split data into subplots based on a categorical variable. facet_wrap(~ cyl)
5
Statistics
Statistical transformations like smoothing, binning, or counting. stat_smooth(), stat_count()
6
Coordinates
The coordinate system: Cartesian, polar, flipped. coord_flip(), coord_polar()
7
Themes
Non-data appearance: fonts, background, grid lines, legend position. theme_minimal()

Building a plot step by step

R Layered construction 
library(ggplot2)

# Step 1: Data + aesthetics
ggplot(mtcars, aes(x = wt, y = mpg))

# Step 2: Add a geometry
ggplot(mtcars, aes(x = wt, y = mpg)) +
  geom_point()

# Step 3: Map a third variable to color
ggplot(mtcars, aes(x = wt, y = mpg, color = factor(cyl))) +
  geom_point(size = 3)

# Step 4: Add a smooth line layer
ggplot(mtcars, aes(x = wt, y = mpg, color = factor(cyl))) +
  geom_point(size = 3) +
  geom_smooth(method = "lm", se = FALSE)

# Step 5: Add labels
ggplot(mtcars, aes(x = wt, y = mpg, color = factor(cyl))) +
  geom_point(size = 3) +
  geom_smooth(method = "lm", se = FALSE) +
  labs(title = "Weight vs MPG", color = "Cylinders")

# Step 6: Apply a theme
ggplot(mtcars, aes(x = wt, y = mpg, color = factor(cyl))) +
  geom_point(size = 3) +
  geom_smooth(method = "lm", se = FALSE) +
  labs(title = "Weight vs MPG", color = "Cylinders") +
  theme_minimal(base_size = 13)

Aesthetics (aes)

The aes() function maps variables in your data to visual properties of the plot. There are two kinds: mapped aesthetics (inside aes()) and fixed properties (outside aes()).

AestheticMaps toExample
xHorizontal positionaes(x = weight)
yVertical positionaes(y = height)
colorOutline / stroke coloraes(color = species)
fillFill color (bars, areas)aes(fill = group)
sizePoint size / line widthaes(size = population)
shapePoint shape (circle, square…)aes(shape = type)
alphaTransparency (0=invisible, 1=solid)aes(alpha = confidence)
linetypeSolid, dashed, dotted…aes(linetype = group)
labelText labelsaes(label = name)
groupGrouping without visual mappingaes(group = id)

Mapped vs Fixed aesthetics

R Inside vs outside aes() 
# MAPPED — color changes based on data
ggplot(mtcars, aes(x = mpg, y = wt, color = factor(cyl))) +
  geom_point()

# FIXED — all points are blue, size 4
ggplot(mtcars, aes(x = mpg, y = wt)) +
  geom_point(color = "blue", size = 4, alpha = 0.7)

# BOTH — shape mapped to data, color fixed
ggplot(mtcars, aes(x = mpg, y = wt, shape = factor(cyl))) +
  geom_point(color = "steelblue", size = 3)

Faceting

Faceting splits your data into multiple subplots, each showing a subset of the data. This is extremely useful for comparing patterns across groups.

Use facet_wrap() when faceting on a single variable. It wraps panels into a 2D grid automatically.

R facet_wrap examples 
# Basic facet_wrap
ggplot(mtcars, aes(x = mpg, y = wt)) +
  geom_point(color = "steelblue", size = 3) +
  facet_wrap(~ gear)          # One panel per gear

# Control layout
ggplot(mtcars, aes(x = mpg, y = wt)) +
  geom_point() +
  facet_wrap(~ cyl, nrow = 1)  # Force single row

# Free scales per panel
ggplot(mtcars, aes(x = mpg, y = wt)) +
  geom_point() +
  facet_wrap(~ cyl, scales = "free")

# Iris example from the source files
ggplot(iris, aes(x = Sepal.Width, y = Petal.Width, fill = Species)) +
  geom_bar(stat = "identity") +
  facet_wrap(~Species) +
  labs(title = "Petal Width by Species")

Use facet_grid() when you want a strict grid of rows AND columns based on two variables.

R facet_grid examples 
# rows ~ columns formula syntax
ggplot(mtcars, aes(x = mpg, y = wt)) +
  geom_point() +
  facet_grid(am ~ cyl)  # am = rows, cyl = columns

# Only column facets
ggplot(mtcars, aes(x = mpg, y = wt)) +
  geom_point() +
  facet_grid(. ~ cyl)   # . means no faceting in that direction

# Free scales in one dimension
ggplot(mtcars, aes(x = mpg, y = wt)) +
  geom_point() +
  facet_grid(am ~ cyl, scales = "free_y")

Scales

Scales control how data values are translated to visual properties. Every aesthetic mapping has a corresponding scale function.

R Common scale functions 
# Axis scales
scale_x_continuous(breaks = seq(10, 35, by = 5))
scale_y_log10()
scale_x_date(date_labels = "%Y-%m")
scale_x_reverse()       # Reverse the axis

# Color/fill scales — continuous
scale_color_gradient(low = "white", high = "darkred")
scale_fill_gradient2(low="blue", mid="white", high="red")

# Color/fill scales — discrete
scale_color_manual(values = c("red", "blue", "green"))
scale_fill_brewer(palette = "Set2")
scale_color_viridis_d()  # Colorblind-friendly

# Size / alpha
scale_size_continuous(range = c(1, 10))
scale_alpha_continuous(range = c(0.2, 1))

# Formatting y-axis as percent
scale_y_continuous(labels = scales::percent_format())
scale_y_continuous(labels = scales::comma)
