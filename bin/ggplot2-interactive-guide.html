What is ggplot2?

ggplot2 is an R package created by Hadley Wickham based on Leland Wilkinson's Grammar of Graphics. It provides a coherent system for describing and building graphs declaratively. Instead of telling R how to draw a plot step-by-step, you describe what data to use, how to map it to visual properties, and what geometric shapes to use.

Every ggplot2 plot is built from the same few components: data, a set of aesthetic mappings, and at least one layer. Additional components like scales, coordinate systems, and themes refine the appearance.

Basic ggplot2 template 
# Install (once)
install.packages("ggplot2")

# Load
library(ggplot2)

# The minimal template
ggplot(data = <DATA>, aes(<MAPPINGS>)) +
  <GEOM_FUNCTION>()
💡

Tip: ggplot2 is part of the tidyverse. You can load all tidyverse packages at once with library(tidyverse) which includes ggplot2, dplyr, tidyr, and more.

Grammar of Graphics

Every ggplot2 plot is built from layered components. Understanding the grammar unlocks the full power of the package.

1
Data
The raw data frame that drives the plot
2
Aesthetics (aes)
Mapping data variables to visual properties (x, y, color, size, shape…)
3
Geom
The geometric object representing data (point, line, bar, area…)
4
Stat
Statistical transformation applied before drawing (identity, count, density…)
5
Scale
Controls how data values map to aesthetic values; also manages legends
6
Coordinate System
The space where data is drawn: Cartesian, polar, flipped, map…
7
Facet
Splits data into small multiples (panels) by a categorical variable
8
Theme
Controls all non-data visual elements: fonts, backgrounds, grid lines…

Building a Plot Step-by-Step

r – Layer by layer
library(ggplot2)

# Step 1: Data + aesthetic mapping
ggplot(mtcars, aes(x = wt, y = mpg))

# Step 2: Add a geometric layer
ggplot(mtcars, aes(x = wt, y = mpg)) +
  geom_point()

# Step 3: Map another variable to color
ggplot(mtcars, aes(x = wt, y = mpg, color = factor(cyl))) +
  geom_point(size = 3)

# Step 4: Add a smooth trend line
ggplot(mtcars, aes(x = wt, y = mpg, color = factor(cyl))) +
  geom_point(size = 3) +
  geom_smooth(method = "lm", se = FALSE)

# Step 5: Apply a clean theme
ggplot(mtcars, aes(x = wt, y = mpg, color = factor(cyl))) +
  geom_point(size = 3) +
  geom_smooth(method = "lm", se = FALSE) +
  labs(title = "Weight vs Fuel Efficiency",
       x = "Weight (1000 lbs)", y = "Miles per Gallon",
       color = "Cylinders") +
  theme_minimal()
📌

Key insight: Layers are added with +. Each layer can override aesthetics from the base ggplot() call. Aesthetics set inside aes() are mapped from data; those set outside aes() are fixed constants.

aes() vs. Fixed Properties

r
# MAPPED: color depends on a data variable
geom_point(aes(color = species))

# FIXED: every point is red (value, not variable)
geom_point(color = "red")

# MIXED: fill mapped to data, alpha fixed
geom_bar(aes(fill = category), alpha = 0.8)

Aesthetics (aes)

Aesthetic mappings link data variables to visual properties. They are the core of how ggplot2 encodes information.

AestheticDescriptionCommon Values

colorBorder / line colorFactor or numeric variable

sizePoint size or line widthNumeric variable
shapePoint shape (0–25)Factor variable
alphaTransparency (0–1)Numeric variable
linetypeLine type (solid, dashed…)Factor variable
labelText label for geom_text/labelCharacter variable

Complete aes() Examples

r
library(ggplot2)

# Scatter plot with multiple mapped aesthetics
ggplot(iris, aes(x = Sepal.Length,
                  y = Sepal.Width,
                  color = Species,
                  shape = Species,
                  size = Petal.Length,
                  alpha = Petal.Width)) +
  geom_point() +
  theme_minimal()

# Size and alpha as fixed values
ggplot(iris, aes(x = Sepal.Length, y = Sepal.Width)) +
  geom_point(color = "steelblue", size = 3, alpha = 0.6)
⚠️

Common mistake: Putting a color value inside aes(), e.g. aes(color = "red"), will create a legend with a single value "red" — it won't color points red. Use geom_point(color = "red") instead.

Legend Customization

Legends are created automatically when you map a variable to color, fill, shape, size, or alpha. Here's how to control every aspect of them.

Adding a Legend

r
# Auto legend: map variable to color or fill
ggplot(df, aes(x = x, fill = group)) +
  geom_density(alpha = 0.5)

Legend Title

r – Three approaches
# Option 1: guides()
guides(fill = guide_legend(title = "Group"))

# Option 2: labs()
labs(fill = "Group")

# Option 3: scale function
scale_fill_discrete(name = "Group")

# Remove title entirely
theme(legend.title = element_blank())

Legend Position

r
# Standard positions: "top", "bottom", "left", "right", "none"
theme(legend.position = "top")

# Inside the plot (coordinates 0–1)
theme(legend.position = c(0.85, 0.15),        # bottom-right corner
      legend.background = element_rect(fill = "white",
                                          color = "grey70"))

# Horizontal legend (useful for "bottom")
theme(legend.position  = "bottom",
      legend.direction = "horizontal")

Legend Appearance

r
theme(
  legend.title     = element_text(face = "bold", size = 12),
  legend.text      = element_text(size = 11),
  legend.key.size  = unit(1, "cm"),
  legend.background= element_rect(fill = "lightblue", colour = 1),
  legend.margin    = margin(8, 8, 8, 8)
)

# Change symbol size in scatter plot legend
guides(color = guide_legend(override.aes = list(size = 5)))

Removing Legends

r
# Remove all legends
theme(legend.position = "none")

# Remove only the fill legend (keep color)
guides(fill = "none")

# Per-geom: hide from legend
geom_point(show.legend = FALSE)

Lines, Segments & Arrows

Add reference lines, drawn segments, curves, and annotated arrows to highlight patterns in your data.

Reference Lines

r
set.seed(1)
df <- data.frame(x = rnorm(100), y = rnorm(100))

ggplot(df, aes(x = x, y = y)) +
  geom_point() +
  # Vertical line at x = 0
  geom_vline(xintercept = 0, linetype = 2, color = "red") +
  # Horizontal line at y = 0
  geom_hline(yintercept = 0, linetype = 3, color = "blue") +
  # Diagonal line: y = intercept + slope * x
  geom_abline(intercept = 0, slope = 0.5, color = "green")

Segments & Arrows

r
ggplot(df, aes(x = x, y = y)) +
  geom_point() +
  # Plain segment
  geom_segment(x = -2, y = 1, xend = 0, yend = 0,
               color = "orange", lwd = 1.2) +
  # Arrow annotation
  geom_segment(x = 1, y = 2, xend = 0.2, yend = 0.5,
               color = "purple",
               arrow = arrow(length = unit(0.3, "cm"),
                              type = "closed"))

Curves

r
ggplot(df, aes(x = x, y = y)) +
  geom_point() +
  geom_curve(x = -2, y = 1, xend = 1, yend = -1,
             curvature = -0.3,  # Negative = left-handed curve
             color = "steelblue",
             arrow = arrow(length = unit(0.3, "cm")))

For geom_vline and geom_hline, you can pass a vector to draw multiple lines at once: geom_vline(xintercept = c(-1, 0, 1))

Faceting & Multi-Panel

Faceting splits a plot into multiple panels — one per group — making it easy to compare distributions and trends across subsets.

facet_wrap() – One Variable

r
ggplot(iris, aes(x = Sepal.Length, y = Sepal.Width, color = Species)) +
  geom_point(show.legend = FALSE) +
  facet_wrap(~Species,
             nrow = 1,             # Force 1 row
             scales = "free",      # Each panel has its own scale
             strip.position = "bottom")  # Labels below

facet_grid() – Two Variables

r
ggplot(diamonds, aes(x = carat, y = price)) +
  geom_point(alpha = 0.2, size = 0.5) +
  facet_grid(cut ~ color,      # rows=cut, cols=color
             scales = "free_x")

# Alternative syntax with vars()
facet_grid(rows = vars(cut), cols = vars(color))

Highlight Groups Behind Panels

r
ggplot(iris, aes(x = Sepal.Length, y = Sepal.Width, color = Species)) +
  # Grey background: all data without Species variable
  geom_point(data = transform(iris, Species = NULL),
             colour = "grey80", size = 2) +
  # Colored foreground: current group
  geom_point(show.legend = FALSE, size = 2) +
  facet_wrap(~Species)

Customizing Strips

r
ggplot(iris, aes(x = Sepal.Length, y = Sepal.Width)) +
  geom_point() +
  facet_wrap(~Species) +
  theme(
    strip.text       = element_text(face = "bold", color = "white", size = 13),
    strip.background = element_rect(fill = "#3d5afe",
                                     color = "#1a237e", linewidth = 1),
    panel.spacing    = unit(8, "pt"),         # Space between panels
    panel.border     = element_rect(fill = "transparent",
                                     color = "#ccc")
  )

Coordinate Systems

Coordinate systems control how data coordinates are translated to the plane of the plot. ggplot2 offers linear and non-linear options.

FunctionUse Case
coord_cartesian()Zoom without removing data (use instead of scale limits)
coord_fixed()Equal aspect ratio on x and y axes
coord_flip()Rotate x and y axes (e.g. horizontal bar charts)
coord_trans()Transform axes post-stat (log, sqrt…)
coord_polar()Polar coordinates (pie charts, wind roses)
coord_map()Map projections (Mercator, orthographic…)
coord_quickmap()Quick aspect-ratio fix for maps

Code Examples

r – Zoom without dropping data
p <- ggplot(df, aes(x = x, y = y)) + geom_point() + geom_smooth()

# BAD: drops points, refits smooth
p + scale_x_continuous(limits = c(-1, 1))

# GOOD: only zooms view, keeps full smooth
p + coord_cartesian(xlim = c(-1, 1), ylim = c(-2, 2))
r – Flip axes
# Horizontal bar chart
ggplot(df, aes(x = group, y = value, fill = group)) +
  geom_bar(stat = "identity") +
  coord_flip() +
  theme(legend.position = "none")

# Horizontal boxplot
ggplot(iris, aes(x = Species, y = Sepal.Length)) +
  geom_boxplot() + coord_flip()
r – Polar / Pie
# Pie chart (stacked bar in polar coords)
pie_df <- data.frame(group = c("A","B","C"), val = c(35, 45, 20))

ggplot(pie_df, aes(x = "", y = val, fill = group)) +
  geom_bar(stat = "identity", width = 1) +
  coord_polar(theta = "y") +   # angle = y variable
  theme_void()
r – Axis transformation
# Log transform AFTER stat computation
ggplot(diamonds, aes(x = carat, y = price)) +
  geom_point(alpha = 0.1) +
  geom_smooth(method = "lm") +
  coord_trans(x = "log10", y = "log10")

# Vs. transform BEFORE stat (different result!)
scale_x_log10()
scale_y_log10()

Combining Plots

Arrange multiple ggplot2 objects into composite figures using patchwork, cowplot, or gridExtra.

patchwork – The Easiest Way

r – patchwork operators
library(patchwork)

# Side by side
p1 + p2

# In a row (always 1 row)
p1 | p2 | p3

# Stacked (always 1 column)
p1 / p2

# Complex nested layout
(p1 | p2) / p3        # 2 on top, 1 spanning bottom
p1 | (p2 / p3)        # 1 on left, 2 stacked on right

# Apply a theme to ALL plots
p1 + p2 + p3 & theme_classic()
r – Layout control & annotation
# Custom design: numbers = plot positions, # = empty space
design <- "
  11#

Bar Charts & geom_bar

Bar charts are among the most common visualizations. ggplot2 offers flexible options for vertical, horizontal, stacked, 100%-stacked, and grouped bars.

r – Simple bar chart
df1 <- data.frame(values = c(5, 2, 7, 2),
                   group  = LETTERS[1:4])

ggplot(df1, aes(x = group, y = values, fill = group)) +
  geom_bar(stat = "identity", width = 0.6) +
  scale_fill_brewer(palette = "Set2") +
  theme_minimal() +
  theme(legend.position = "none")
r – Stacked bar chart
df2 <- data.frame(
  values    = c(3, 2, 6, 3, 4, 3, 8, 2),
  maingroup = rep(LETTERS[1:4], each = 2),
  subgroup  = letters[1:2]
)

ggplot(df2, aes(x = maingroup, y = values, fill = subgroup)) +
  geom_bar(stat = "identity", position = "stack")
r – 100% stacked (filled)
library(scales)

ggplot(df2, aes(x = maingroup, y = values, fill = subgroup)) +
  geom_bar(stat = "identity", position = "fill") +
  scale_y_continuous(labels = percent_format()) +
  labs(y = "Percentage")
r – Grouped (dodged) bar chart
ggplot(df2, aes(x = maingroup, y = values, fill = subgroup)) +
  geom_bar(stat = "identity", position = "dodge",
           width = 0.7) +
  scale_fill_manual(values = c("#7c6aff", "#ff6b6b")) +
  theme_minimal()
r – Horizontal with value labels
ggplot(df1, aes(x = reorder(group, values), y = values, fill = group)) +
  geom_bar(stat = "identity") +
  geom_text(aes(label = values), hjust = -0.3, size = 4) +
  coord_flip() +
  theme_minimal() +
  theme(legend.position = "none")
